## 五、每周三件事（日常操作备忘）

```bash
# 1. 做完本周实验后，查看哪些文件被改动了
git status

# 2. 把改动放进"待寄包裹区"（暂存区）
git add .

# 3. 打包封存，并写一句这次做了什么的说明
git commit -m "week-01: 完成环境搭建与 Hello World"
```

每周的最新版本，建议同步到 GitHub：

```bash
git push origin main
```

## 六、分支约定

| 分支 | 用途 |
| --- | --- |
| `main` | 主分支，只存放**已通过检查**的最终版本 |
| `week-xx` | 每周实验的独立工作分支，完成后合并回 `main` |

## 七、环境与规范

- Python ≥ 3.10（推荐 3.11+）
- 包管理：`pip` / `conda`
- 依赖记录：每周实验目录下提供 `requirements.txt`
- 编码统一 **UTF-8**，换行符由 Git 自动处理
- **禁止**提交任何密钥（API Key）、大体积原始数据、压缩包

### 环境复现

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r experiments/week-xx/requirements.txt
```
